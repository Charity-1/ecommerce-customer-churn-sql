Objective: Query relational database schemas to isolate high-value revenue drivers and evaluate user churn profiles.

### Project Insights & Solutions
1. Product Performance Metrics: Evaluating transactional tables through structural aggregations (`SUM`, `COUNT`) highlighted that Electronics represent the highest grossing revenue channel, despite lower relative order transaction frequencies compared to retail clothing categories.
2. Relational Customer Slicing: Utilizing relational `INNER JOIN` operations mapped customer purchasing timelines. Filtering datasets specifically for current-year transactions identified distinct user cohorts failing to execute repeat orders, flagging clear risk categories for target marketing interventions.
